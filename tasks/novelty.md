# Task: Novelty and OR/MS Positioning

Novelty assessment is time-sensitive. Search current literature when possible.

## Step N1 — Define the primitive contribution

Write novelty in mathematical rather than application language: decision-dependent information structure, new ambiguity-set geometry, joint parameter/distributional uncertainty, new robustness criterion, finite-sample calibration for a learned set, exact reformulation for a previously intractable class, etc.

## Step N2 — Build the nearest-neighbor matrix

Use columns `paper | uncertainty object | decision timing | ambiguity/uncertainty set | decision dependence | recourse | guarantee | reformulation | algorithm | application`. The new paper must differ on a consequential dimension.

## Step N3 — Red flags

Novelty is often weak if it only replaces a norm, changes a Wasserstein cost and rediscovers a regularizer, adds a tuning parameter, applies a known reformulation to a new application, adds side information but treats it as fixed after estimation, combines known ambiguity sets without new statistical/computational insight, or proves a direct corollary as a new paradigm.

## Step N4 — Contribution chain

Require `operational failure -> missing primitive -> mathematical obstruction -> new result -> practical/statistical consequence`.

## Step N5 — Reviewer attack

Ask whether the model is a reparameterization, whether an equivalence theorem collapses novelty, whether the ambiguity set is a regularizer in disguise, whether the finite-sample result is inherited immediately from generic containment, whether the algorithm is actually needed, and whether experiments favor the method by construction.

## Verdict

Do not assign top-journal potential merely from technical complexity. Judge conceptual novelty, theoretical necessity, computational usefulness, and operational relevance jointly.
